# Deep_Learning_Pneumony_Detection

Ce projet concerne l'entraînement de modèles de réseaux de neurones convolutifs (CNN) pour détecter la présence de pneumonie à l'aide d'images médicales. 

Utilisation de méthodes avancées : Data augmentation, transfer learning et fine tuning

Utilisation de la bibliothèque Pytorch en Python
